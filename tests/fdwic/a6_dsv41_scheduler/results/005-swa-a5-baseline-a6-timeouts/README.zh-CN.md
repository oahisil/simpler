
# 005　A5 迁移版 SWA 单卡性能与 L2 调度开销

**A5 迁移版每轮执行业务核 632 次，25 份输出参考全部通过。** 同一套四核 C++ 实现在 L0 的核窗口为 **156.759 µs**，开启 L2 后为 **168.817 µs**。当前迁移版各项实测均来自同一提交、同一张 A5、同一回放包，每个采集等级独立预热 1 轮、正式测量 10 轮。A6 五分块 C++ 配置已在单卡完成 L0/L2 实测，25 份输出校验通过；A6 L2 的整图、生命周期、逐成员和 Host 数据已回填；A6 L1 也已采集，L1 同步约束下界为 209.690 µs，10 轮均 OPTIMAL。A6 本次原始 JSON：[L0 metrics](a6-cpp-L0-metrics.json)、[L1 metrics](a6-cpp-L1-metrics.json)、[L1 bound](a6-cpp-L1-bound.json)、[L2 metrics](a6-cpp-L2-metrics.json)、[L0 result](a6-cpp-L0-result.json)、[L1 result](a6-cpp-L1-result.json)、[L2 result](a6-cpp-L2-result.json)、[L2 泳道 JSON](a6-cpp-L2.json)（[xz](a6-cpp-L2.json.xz)）。[A6 问题定位](issues.zh-CN.md)

## 复现本次 A5 测量

从迁移版实测提交 `a78b680908bc` 使用 CANN 9.3.0 和仓库 `pto_isa.pin` 构建 A5 HBG DFX 运行库及回放包，选择 `--platform a5 --kernel-set cpp`，保留 A5 原分块。单卡分配一次，三组均使用同一设备、同一 runner 和同一回放包。每级传给 native runner 的尾部参数分别为 `0 1 10`、`1 1 10`、`2 1 10`（等级、预热数、正式轮数），均使用 `--runtime=host_build_graph` 并关闭额外 AICPU 生命周期细分。使用 `performance.py --platform a5 --shared-device-clock` 汇总各级数据，L2 加 `--trace` 导出代表轮；L1 的 rank0 交给 `sync_bound.py` 计算下界。[构建与运行](../../doc/usage.zh-CN.md) · [性能统计](../../performance.py)
