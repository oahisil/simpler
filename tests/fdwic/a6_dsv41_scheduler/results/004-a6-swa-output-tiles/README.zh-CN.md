# 阶段 004　A6 单卡 SWA 的 HC post 与 O-B 分片

**A6 采用已测的 `post54-ob54` 组合。** 相对同卡同批的原配置，L0 核窗口从 **316.570 降至 290.068 µs**（节省 **26.502 µs，8.37%**），Device wall 从 **404.002 降至 377.707 µs**（节省 **26.295 µs，6.51%**）。组合及两个单项配置均通过 30／30 个可写缓冲区校验。A5、A6 在本对照中均按原计划提交 80 个补零 block。[指标 JSON](metrics.json)

## 同卡对照

A6 有 54 个 C 核、54 个 V 核。四组实测复用同一张卡、固定输入、参考输出和 HBG 运行时，均沿用 003 的 t17／t20 分片。L0、L1、L3 各预热 1 轮，表中时间为 10 个正式轮的算术均值，单位 µs。003 历史行用于跨阶段查看，004 的收益均以本表第二行为基准。[003 归档](../003-a6-swa-blocks/README.zh-CN.md)

| A6 配置 | 每轮实例 | 输出校验 | 计算前 | L0 核窗口 | 计算后 | L0 Device wall | L1 同步约束下界 | L0 距下界 |
| ------- | -------: | -------: | -----: | --------: | -----: | -------------: | --------------: | --------: |
| 003 历史 · `quant54-oa54` | 604 | 30／30 | 53.210 | 319.060 | 34.420 | 406.690 | 207.210 | 53.98% |
| 004 同批对照 · `quant54-oa54` | 604 | 30／30 | 51.539 | 316.570 | 35.893 | 404.002 | 209.010 | 51.46% |
| 仅 HC post · `post54` | 594 | 30／30 | 54.176 | 299.023 | 35.456 | 388.655 | 200.210 | 49.35% |
| 仅 O-B · `ob54` | 626 | 30／30 | 50.951 | 311.468 | 34.574 | 396.992 | 199.770 | 55.91% |

L0 核窗口从首个计算核开始到末个计算核结束，加上计算前后两段得到 Device wall，末位有舍入差。L1 下界按各配置的实测核体时长、任务依赖、MIX／同步启动和 54C／54V 容量分别求解。时长按 100 ns 向下量化，每组十轮均得到最优解。**距下界 =（L0 核窗口 ÷ L1 下界 − 1）× 100%。** 仅改 O-B 时，实测窗口缩短 5.102 µs，下界缩短 9.240 µs，因此距下界比例升至 55.91%。

## 哪个任务带来收益

| A6 配置 | L3 t21 O-B 跨度 | L3 t27 HC post 跨度 | L3 核窗口 | L3 Device wall |
| ------- | --------------: | ------------------: | --------: | -------------: |
| 同批对照 | 37.289 | 56.147 | 633.469 | 1180.725 |
| 仅 HC post | 35.761 | **18.052** | 593.991 | 1127.316 |
| 仅 O-B | **30.226** | 56.910 | 624.042 | 1182.339 |
| **HC post + O-B** | **28.707** | **18.243** | **582.659** | **1130.324** |

- **t27 HC post 的单项收益最大。** A5 的 64 个 V 核能一批接下原来的 64 个 block，A6 有 54 个 V 核。实测版本把 160 个工作块分给 54 个 block，每个工作块在一次调用内算完四路输出，尾部也能复用输入和系数。t27 的 L3 首末实例跨度缩短 **38.095 µs**，整层 L0 核窗口缩短 **17.547 µs**。这次同时改变了 block 数和尾部计算方式，数据给出的是两项合计收益。[HC post 实现](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/hc_post.cpp)
- **t21 O-B 用上更多 C 核。** A5 的 32 个 C 核各算 160 列，刚好覆盖 5120 列。A6 改为 52 块各 96 列、2 块各 64 列，54 个 C 核都有独立输出。单改 t21，L3 任务跨度缩短 **7.063 µs**，整层 L0 核窗口缩短 **5.102 µs**。[O-B 实现](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/o_proj_b.cpp)

## 复现

当前 A6 默认构建 `post54-ob54`。同批原配置可用 `--a6-plan quant54-oa54` 重建。单项实验的构建入口保存在提交 `6610c766c`，分别传 `--a6-plan post54` 或 `--a6-plan ob54`。各包均含 19 个核和 16 个计算任务，离线逐项核对了 2735 条计划记录以及两处核的输出覆盖。收敛配置后重新离线构建，A6 默认组合（616 个实例）和 A5 对照（578 个实例）的计划、19 份核机器码及 callable 均与各自原包逐字节一致。[单卡复测命令](../../doc/a6-environment.zh-CN.md#已有性能数据的复测方法)
