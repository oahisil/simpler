AICore / 常驻调度循环

一个 block 拿到核以后

领取只确定“谁负责”。前驱已完成、参数已绑定、需要的协同条件已满足，才允许读取业务输入并进入核函数。

等待时还能看另一份工作

普通任务本核栈内槽位 0本核栈内槽位 1MIX 成员对应 SSBUF 区 0对应 SSBUF 区 1

每个 AIC 或 AIV worker 在常驻调度函数的私有栈帧中保留两个普通槽位。每个槽位记录任务号、block 编号、前驱检查进度和调用参数索引； 完整参数在设备 GM。MIX 成员也保留自己的本核状态，组内 C/V 通过 SSBUF 的两份共享描述符交接工作。 槽位 0 等前驱时，本核可以先执行槽位 1 已就绪的 block。

什么开销被省掉了？ Host 预绑参数省去设备重复拼参；缓存已完成的前驱前缀省去重复查询；双槽让等待中的工作少挡住另一份可执行工作。它们分别作用于不同阶段。

96 核同址访问，为什么 A6 实测分支保留 GM 计数？

002 使用的双槽 HBG 在启动前选好整轮完成数的读写位置。取得可用的 CntNotify ADD 映射时，每完成一个逻辑任务， AICore 就给 STARS 通知 SRAM 中的计数器加一，AICPU 从同一计数器的 SET/read 地址读进度。 在 A6 的 GM 路径上，AICore 直接给 GM 中的 64 位变量加一，AICPU 直接读该变量，全程无需在两处之间拷贝。

96 核同时起跑，每核访问同一个 32 位地址一次。下表是每轮最后一核完成相对最早起跑的耗时，取 192 轮均值。A5 用 32C＋64V，A6 用 48C＋48V。读返回值已消费，写含 DSB_DDR。

操作 A5 µs A6 µs
GM 普通读 1.660 0.503
GM atomicAdd(0) 读 16.387 0.990
CntNotify SET/read 地址读 1.199 1.225

A6 选择 GM 的直接原因是 ADD 直映射返回 507899；按 A5 别名 SET＋0x08 发出 96 次加一命令后，终值仍为 0。 上表中 A6 同址 GM 原子读的耗时约为 A5 的 1/16.6。A6 另测 96 次 64 位 GM atomicAdd(1)，最后一核平均 1.051 µs，193／193 轮由 AICore 读到 96。可见 A6 的同址原子竞争代价已小很多。A5 STARS ADD(1) 的同口径计时和 A6 同卡切换后端的 SWA 数据仍缺，因此不能量化两条加一路径的差距或切换后端的整层收益。

标量调度、缓存和屏障分别花在哪里？

AIC/AIV 上的标量单元执行目录游标、依赖检查和状态判断。频繁读共享元数据会增加标量访存及缓存工作量。DCCI 按适用模式维护缓存，DSB 按指定域保证访问顺序或完成；同组交接还需正确的发布与观察协议。缩小热数据、减少轮询、合并缓存维护是不同的优化。阶段 004 未单独测量标量指令速度或 TCM 预取收益。

A6 单卡 SWA 同批对照

两种尾部任务，两个原因

t27 · HC post · L3 单项跨度56.147 → 18.052µs，64 个 V block 改为 54 个
t21 · O-B · L3 单项跨度37.289 → 30.226µs，32 块输出列改为 54 块

HC post 把 160 个 chunk 分给 54 个 V，每个 chunk 一次处理四路输出，省去第二批下发并复用输入。O-B 将 5120 列从 32×160 改为 52×96＋2×64，让更多 C 核有独立输出。实测同时调整两项，L0 核窗口缩短 26.502 µs。单项 L3 跨度有并行重叠，不能直接加成整层收益。

下界怎样读

把另一组 L1 逐核时长按 100 ns 向下取整，保留任务依赖、核数、不可抢占 block、MIX 配对和同步启动要求，假定调度本身耗时为零。每个配置逐轮求解，然后取十轮均值。

004 组合：核窗口 290.068 µs，下界 192.760 µs，距下界 50.48%。差额 97.308 µs 是实测与模型的差距。核执行过程中暴露的空隙、资源分配、调度及两种采集口径都可能影响这一差额。

PR #3189 · 截至 2026-11-20 仍开放

L2 为什么能看见“等”

在关键状态变化处记时间，转换时用相邻端点画区间。例：第一次发现未完成前驱、后来确认全部满足，两点围出了本槽位的依赖等待。中间同一物理核可以推进别的槽位，所以一条长等待色块不等于标量一直忙，也不等于整核一直空闲。

这份 PR 还调整了 A5 在窄任务与宽 SPMD 任务竞争时的目录顺序，并允许 AIV0 发布 MIX 后先处理已领取的较早普通工作。其 A5 SWA 配对 L0 均值为 187.990 → 175.583 µs（−6.60%），七用例均值之和下降 1.67%，其中三个用例略升。衡量 L2 采集膨胀 需同版本同用例比较 L2/L0，PR 中这组 L0 数字仅衡量执行策略变化。
